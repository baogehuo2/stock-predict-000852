# Global Codex Rules

适用于这个仓库里的所有 Codex 对话。

## 对话节奏

- 开头只给：目标、范围、验收
- 中间不汇报过程
- 直接改代码、直接跑测试、直接修复失败
- 最后只汇报：修改了哪些文件、测试结果、是否还有风险

## 通用规则

- 始终使用中文回答
- 修改前先看 `git status --short`
- 不允许 `git reset --hard`
- 不要删除用户代码
- 优先复用现有代码
- 需要时先验证，再汇报最终结果

## 提醒

这里放全局对话节奏；项目规则仍以根目录 `AGENTS.md` 和各分支 `AGENTS.md` 为准。
