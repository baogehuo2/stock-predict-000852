# Buy 1.0 概率分层评估

本文记录 1.0 买入模型在 2021 至 2026-06-10 滚动验证区间内的概率分层结果，用于判断是否可以降低阈值来增加信号数量。

## 评估口径

- 数据来源：滚动验证明细 `model2_political_feature_ablation_details.csv` 中的 `00_v1_baseline`
- 区间：2021 至 2026-06-10
- 样本：牛市硬门控后的交易日
- 标签：未来 7 日收益大于 0.5%
- 去重：7 个交易日内只保留第一条信号
- 目标：判断 `watch / long / strong` 分层是否可行

## 结论

1. 不建议把普通买入阈值降到 0.50 或 0.55。
   - `watch_long` 准确率只有 48.39%。
   - `0.55-0.60` 最差未来 7 日收益达到 -11.2282%。
   - 放宽阈值虽然增加信号，但会明显降低质量。

2. 1.0 概率不是单调越高越好。
   - `0.70-0.75` 是最好的纯 1.0 分层，precision 80.00%。
   - `>=0.80` 反而只有 55.00%，说明模型高分段有过拟合或市场状态干扰。

3. 当前最稳妥的普通信号仍是 `buy_proba >= 0.60`。
   - 信号数 36。
   - precision 69.44%。
   - 平均未来 7 日收益 1.7693%。

4. 如果要增加信号，不应靠降低普通阈值，而应靠外部增强层。
   - 政治事件强信号和 CEWC 特强信号比降低阈值更有价值。

## 建议模式

当前建议采用“三层买入模式”，但不要加入低置信度观察买入：

| 层级 | 规则 | 用途 |
| --- | --- | --- |
| `neutral` | 不满足任何买入规则 | 不交易 |
| `long` | 1.0 模型 `buy_proba >= 0.60` | 普通买入 |
| `strong_long` | 政治事件增强 `political_proba >= 0.70` | 高质量增强买入 |
| `very_strong_long` | CEWC 增强 `cewc_proba >= 0.75` | 稀疏高质量买入 |

暂不建议：

- `watch_long = buy_proba >= 0.50`
- `light_long = buy_proba >= 0.55`

原因是低阈值会显著增加噪音，而且 2026 年低阈值分层表现很差。

## 后续动作

- 正式信号输出继续保留 `buy_proba >= 0.60`。
- 增强信号继续使用政治事件分层。
- 不再为增加信号数量而直接降低 1.0 阈值。
- 后续若要提高覆盖率，优先新增“事件方向/政策强弱/情绪解释层”，而不是降低阈值。
