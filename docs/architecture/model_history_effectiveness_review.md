# Buy 模型历史调整与效果复盘

本文用于重新梳理 Buy 模型主线。当前目标是回到效果最好的候选版本，并删除不再继续使用的临时实验脚本。

## 当前保留的最佳候选

当前效果最好的候选策略是：

```text
feature_variant = buy_plus_bottom
rule = three_stage
opportunity_threshold = 0.20
position_threshold = 0.20
risk_threshold = 0.50
```

含义：

- 机会模型：未来 20 日有可交易上涨空间。
- 位置模型：接近人工认可的底部区域。
- 风险模型：过滤未来 20 日容易先大跌的样本。
- 特征：Buy 1.0 特征 + bottom 日线形态特征 + bottom 周线确认特征。

总体结果：

| 指标 | 数值 |
| --- | ---: |
| 信号数 | 11 |
| 未来20日上涨率 | 63.64% |
| 机会标签命中率 | 45.45% |
| 平均未来20日收益 | 4.2211% |
| 平均未来20日最大上涨 | 8.5084% |
| 平均未来20日最大不利波动 | -6.2462% |
| 最差单笔未来20日收益 | -7.1269% |

这个版本不是正式封版模型，而是当前最值得继续研究的候选策略。

说明：

- 表中 Precision 在不同阶段含义不同：
  - 1.0 20日评价：未来20日收益是否大于0。
  - 政治增强7日：未来7日收益是否超过标签阈值。
  - 人工标签：是否命中人工买入窗口。
  - 20日机会：是否满足 `future_mfe_20d >= 3% 且 future_mae_20d > -3%`。
- “最大回撤/最差收益”这里不是完整资金曲线回撤，而是信号后的最差单笔收益或最大不利波动代理。

## 复盘结论

### 1. 单一模型路线不理想

只靠一个模型输出买/不买，会在两个目标之间摇摆：

- 想要信号多，收益就变低。
- 想要收益高，信号就很少。

所以后续不宜继续做“大一统买入模型”。

### 2. 机会模型解决信号数量，但不解决收益

新 20 日机会标签让信号数提升到 40-50 条，但平均收益只有约 0.7%-1.1%。

这说明：

```text
未来20日有机会
不等于
现在就是值得买的好点位
```

机会模型更适合作为观察池。

### 3. 位置模型能提高收益，但会减少信号

加入 bottom 位置模型后，收益明显提高，但信号数回到 10 条左右。

这说明：

```text
机会 + 位置
才更接近可交易买点
```

但它仍然太稀疏。

### 4. 风险模型还没有真正解决问题

当前风险模型仍然没有很好挡住 2022 这种持续下跌环境。

下一阶段如果继续做，重点不是再加机会特征，而是重构风险标签。

## 重新整理后的主线

建议后续先暂停继续加新模型，重新定义策略层：

| 层 | 作用 | 当前状态 |
| --- | --- | --- |
| 机会池 | 找未来20日可能有上涨空间的日期 | 可用，但收益低 |
| 位置确认 | 判断是不是低位/底部区域 | 有价值，但信号少 |
| 风险过滤 | 挡住持续下跌环境 | 当前最弱，需要重构 |
| 强信号增强 | 政治/政策事件增强 | 有价值，但稀疏 |

后续最该做：

1. 不再盲目加特征。
2. 先重构风险标签，重点解决 2022。
3. 把策略输出改成分层：
   - `watch_long`
   - `long`
   - `strong_long`
   - `risk_warning`
   - `blocked`
4. 等分层信号稳定后再回测。
