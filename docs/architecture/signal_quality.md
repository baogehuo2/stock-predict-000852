# 上涨信号质量评估

这个项目当前最重要的不是三分类 accuracy，而是上涨信号有没有统计价值。

## 评估指标

- `predicted up hit rate`
- `future return`
- `signal count`
- `coverage`
- 相对全样本上涨率的 uplift
- 按概率分层后的命中率与收益

## 推荐做法

1. 先做最简单的上涨信号评估
2. 再加概率分层统计
3. 再和简单基线比较
4. 最后才考虑调参或加新特征

## 不建议的做法

- 只看整体 accuracy
- 一上来就大改模型结构
- 频繁重复大规模历史抽取

## 常用验证

- 先跑最小评估脚本
- 再跑对应训练脚本
- 最后只输出结果，不输出冗长过程
